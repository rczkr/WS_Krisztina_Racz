# Developer Portfolio & Application Website
               Krisztina Racz

Ein modernes, responsives Web-Portfolio und Bewerbungsprojekt, entwickelt im Rahmen der IHK-Umschulung zur **Fachinformatikerin für Anwendungsentwicklung**. 

Die Anwendung dient als digitale Visitenkarte, präsentiert absolvierte Softwareprojekte und enthält ein integriertes Kontaktformular sowie eine mehrsprachige Benutzeroberfläche.

---

## 🌟 Hauptfunktionen

* **Projektpräsentation:** Übersicht über entwickelte Webanwendungen (z. B. *KopfFit*, *JumpNova*).
* **Mehrsprachigkeit (DE / HU / EN):** Nahtlose Sprachumschaltung (Deutsch, Ungarisch, Englisch) über ein integriertes Übersetzungselement im Navigationsmenü.
* **Responsive Design:** Optimiert für Desktop- und Mobilgeräte unter Verwendung von modernem CSS/Tailwind CSS.
* **Interaktives Kontaktformular:** Direkte Nachrichtensendung für Rückfragen und Rückmeldungen.
* **Einstellbarer Sprach-Reset:** Automatische Rückstellung auf die deutsche Originalversion beim Neuladen der Seite.

---

## 🛠️ Technologien & Werkzeuge

* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, Tailwind CSS, JavaScript
* **Tools & IDE:** PyCharm, Git, GitHub
* **Deployment:** Render
